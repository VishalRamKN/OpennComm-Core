# Code of conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1.

In short: be decent to people. Harassment, personal attacks and demeaning
comments are not welcome, and neither is dismissiveness towards the people this
software is for.

One thing worth stating plainly because of what this project is: **do not speak
about disabled people as problems to be solved.** The patients who use
OpennComm are the users, not the subject matter. Design arguments should be
about what serves them, and "a patient would never want that" needs evidence,
not assertion.

Report unacceptable behaviour privately to the maintainers through GitHub.
Reports will be handled discreetly.
